# Product Requirements Document

## Product

Codex MCP Workspace for Full-Stack Web Development and Infrastructure Management

## Objective

Create a private GitHub repository containing a collection of MCP servers that extend Codex's capabilities when developing and operating a FastAPI web application.

The system should enable Codex to act as an effective software engineer and DevOps engineer across local development, GitHub repositories, CI/CD pipelines, infrastructure management, deployments, testing, troubleshooting, and documentation lookup.

The system must remain simple, understandable, and maintainable by a solo developer.

## Initial Scope

Start with:

- GitHub MCP
- Docs MCP
- Local Dev MCP
- Browser Testing MCP
- Markdown Memory MCP

Add later:

- AWS Inspection MCP
- Terraform MCP
- Ansible MCP

## Principles

- Simplicity first
- Human-readable code and configuration
- Local-first operation
- Safe by default
- Read-only operations preferred
- Destructive operations separated from inspection capabilities
